# Sales Insights Dashboard (Power BI)

This project is a Power BI dashboard I built as part of a learning course. It uses real-world style data from a company called **AtliQ Hardware** and shows how sales are performing across different regions, products, and customer segments.

## 🎯 What this dashboard does
- Tracks total revenue, profit, and quantity sold  
- Breaks down sales by **region, market, and product**  
- Highlights **top customers** and **high-performing products**  
- Shows year-over-year trends and key insights  

## 📂 What’s inside
- `Sales-Insights-Course-Project.pbix` → The Power BI project file
- If needed, update the dataset path (CSV/Excel files) to refresh the visuals. 

## 🚀 How to use
1. Download or clone this repo.  
2. Open the `.pbix` file in **Power BI Desktop**.  
3. If needed, update the dataset path (CSV/Excel files) to refresh the visuals.  

## 💡 Why I built this
I wanted to practice building dashboards that are both **useful for business decisions** and **easy to understand**. This project helped me get comfortable with:  
- Data cleaning & modeling in Power BI  
- Using DAX for measures  
- Designing clean and interactive visuals
